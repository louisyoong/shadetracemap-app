# ShadeTrace Map

A Flutter app that helps you find sun and shade throughout the day — plan walks, picnics, or outdoor plans around where the shade will be.

## Features

- Interactive shade map with time-of-day slider
- Weather conditions and forecast
- Sun position compass and sun simulator
- Location search and device location support
- Home screen widget
